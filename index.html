What is Surfnet ZK Edge?

An ephemeral Solana network designed for the Solana Privacy Hackathon, providing developers with cutting-edge zero-knowledge primitives and privacy-preserving capabilities.

🔒

ZK Primitives

Access Groth16, PLONK, Bulletproofs, and ZK-STARKs for building privacy-preserving applications.

Developer-Friendly

Free SOL faucet, comprehensive documentation, and hackathon support channels.

SIMD-0296 enabled for larger transactions, perfect for complex ZK proofs.

Supported ZK Technologies

Groth16

Efficient Proofs

Constant-size proofs (~200 bytes) with fast verification. Perfect for confidential transactions and private voting.

PLONK/PlonKY2

Universal SNARKs

Universal trusted setup with recursive proof composition. Ideal for complex business logic privacy.

Bulletproofs

Range Proofs

No trusted setup required. Compact proofs for ranges and values in confidential asset transfers.

ZK-STARKs

Post-Quantum

Quantum-resistant proofs with no trusted setup. Transparent and publicly verifiable.

// Generate a proof for confidential token transfer const proof = await generateTransferProof({ sender: wallet.publicKey, recipient: recipientPubkey, amount: 100, // Hidden from public senderBalance: 1000 // Verified without disclosure }); // Submit confidential transfer transaction const signature = await sendConfidentialTransfer( connection, wallet, proof ); console.log('Private transfer completed:', signature);

// Cast a vote without revealing your choice const voteProof = await generateVoteProof({ voter: wallet.publicKey, proposal: proposalId, vote: 'yes', // Hidden choice voterWeight: tokenBalance }); // Submit private vote const signature = await castPrivateVote( connection, wallet, voteProof ); console.log('Private vote cast:', signature);
